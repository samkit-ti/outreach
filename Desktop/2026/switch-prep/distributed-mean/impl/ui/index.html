Distributed Mean

Index-wise mean of F pre-existing weight vectors, computed by a heterogeneous worker fleet.

A job is the index-wise mean of F weight files × C values each — model-weight vectors that already exist at node-owned S3 URIs, in a federated-learning aggregation setting. The system turns each submitted inputUris[] into a bag of idempotent tasks whose partial results are closed under a 5-ary merge: a map task reads up to 5 input files and writes one partial carrying (Σ-vector, count); a reduce task merges 2–5 partials into one; a single finalize divides by F. Because sums are associative and commutative, partials combine in any order by any worker, so there is no barrier, no coordinator tracking the whole computation, and no pre-built reduction tree — reduce tasks are created eagerly the moment 5 unconsumed partials exist for a job. Workers pull from one Postgres-backed queue (SKIP LOCKED) under least-in-flight fairness ordering, so a slow worker's blast radius is one task and a small job submitted mid-flight is not starved by a 25,000-task convoy. Completion is a theorem rather than a tally: a lone partial whose count == F covers every input file, so it is the answer, and only the finalize commit writes 100 %.
